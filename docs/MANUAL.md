# AC Good Boy 用户手册

> 本手册会随违规清单一起自动更新。随时可用 `/ac-good-boy:manual` 查看最新版本。

## 它做什么

AC Good Boy 是一个"坚决不违规"的 Claude Code 插件。安装后，它会在两个时机检查是否触碰 Anthropic / Claude 使用条款的红线：

1. **你提交提示词时**：命中"禁止"级规则 → 提示词直接被拦下；命中其他规则 → 显示提醒，并要求 Claude 先说明风险、不协助违规部分。
2. **Claude 执行命令、写文件、访问网页之前**：按规则的动作处理 —— ⛔ 禁止（直接拒绝）、❓ 需确认（弹窗由你决定）、⚠️ 提醒（只提示）。

默认：高风险规则 = ⛔ 禁止，中风险规则 = ⚠️ 提醒。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `/ac-good-boy:admin` | 打开管理后台，设置每条规则的动作、添加自定义禁止项、配置自动更新 |
| `/ac-good-boy:rules` | 列出全部规则和当前动作 |
| `/ac-good-boy:check <方案>` | 让 Claude 对照规则自查一个需求或方案 |
| `/ac-good-boy:update` | 立即检查并更新违规清单和本手册 |
| `/ac-good-boy:manual` | 查看本手册 |

## 管理后台

运行 `/ac-good-boy:admin` 后会得到一个 `http://127.0.0.1:...` 地址，在本机浏览器打开即可：

- **默认动作**：分别设置高风险、中风险规则的默认动作。
- **规则**：逐条选择 ⛔ 禁止 / ❓ 需确认 / ⚠️ 提醒 / 关闭，或"按默认"。
- **自定义禁止项**：添加你自己的规则（编号以 C 开头），用正则描述要拦截的内容。
- **忽略的文件路径**：写入这些文件时不检查内容（适合写合规文档时使用）。
- **自动更新**：开关、间隔、更新地址。

后台只监听本机地址，并且每次启动都会生成一次性令牌，其他网页无法调用；闲置 1 小时自动关闭。

在打不开浏览器的环境（例如远程服务器），可以用命令设置：

```
python3 <插件目录>/hooks/cli.py set R04 block      # 某条规则改为禁止
python3 <插件目录>/hooks/cli.py set medium ask     # 中风险默认改为需确认
```

设置保存在 `~/.ac-good-boy/config.json`，插件升级不会覆盖它。

## 自动更新

- 每次开始新会话时，若距离上次检查超过设定间隔（默认 24 小时），插件会下载最新的违规清单（`hooks/rules.json`）和本手册。
- 只有版本号更高、格式和正则全部校验通过的清单才会被采用；下载失败不影响使用，继续用现有清单。
- 自动更新只下载规则数据和文档，**从不下载或执行代码**。插件代码本身的更新请用 `/plugin` 菜单更新插件。
- 你在后台做的设置（动作、自定义规则）不会被更新覆盖。

## 防篡改

R00「不让 AI 自己关掉守卫」写死在代码里：Claude 想修改 AC Good Boy 的配置、已安装的违规清单，或用命令修改规则动作时，都必须由你本人确认。这条规则在后台里也关不掉。

## 遇到误报

- 在提示词或内容里加上 `ac-good-boy:allow`，本次跳过内容检查（防篡改检查不受影响）。
- 在后台"忽略的文件路径"或项目根目录的 `.ac-good-boy-ignore` 里加上文件路径通配符。
- 在后台把这条规则改成"提醒"或"关闭"。
- 欢迎到项目仓库提 issue / PR 修正规则，修正会通过自动更新推送给所有人。
